# Hi, I'm Davide 👋

I'm a Frontend Engineer focused on React and TypeScript, with full-stack experience building Node.js services and REST APIs.

I work on B2B applications, IoT-related products and corporate websites, contributing across the development lifecycle: requirements analysis, reusable frontend components, API integration, backend business logic, code reviews and technical documentation.

My main interests are frontend architecture, maintainable component systems, type-safe application boundaries and developer experience.

## Selected projects

### [PVVerdict](https://github.com/duckycoding-dev/pvverdict)

A local-first web application that estimates solar PV production, self-consumption, savings and payback time using hourly PVGIS data. It compares systems with and without battery storage while keeping consumption data in the browser.

`React` · `TypeScript` · `Recharts` · `Bun` · `Cloudflare Pages` · `Astro`

### [DuckyCoding](https://github.com/duckycoding-dev/ducky-coding)

My developer blog and portfolio, built to publish web-development articles, experiments and memes through a maintainable content workflow.

`Astro` · `TypeScript` · `Tailwind CSS` · `MDX` · `Netlify` · `libSQL`

### [Task Manager](https://github.com/duckycoding-dev/task_manager)

An incremental frontend laboratory built around a reusable task-management backend. The backend is complete, while frontend implementations are developed progressively to explore different patterns, libraries and design approaches.

`Hono` · `TypeScript` · `Drizzle ORM` · `PostgreSQL` · `Zod` · `React`
